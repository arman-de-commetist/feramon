# Как закинуть сайт MONA на hoster.kz

Всё делается за ~20 минут. Команды ниже вставляются в **PowerShell** на компьютере (Пуск → PowerShell).

## 1. Купить сервер на hoster.kz

1. Зайдите на **hoster.kz** → «Услуги» → **«Облачные серверы»**.
2. Раздел **«Облачные серверы»** (hoster.kz/cloud/vps/) → тариф **Cloud 1-1-25** (1 ГБ памяти) — хватит; скрипт сам подстроится под 1 ГБ.
3. Операционная система: **Ubuntu 22.04** или **Ubuntu 24.04**.
4. После оплаты на почту придут: **IP-адрес** сервера (например `185.22.66.10`) и **пароль root**.

## 2. Загрузить сайт на сервер

В PowerShell (вместо `IP` подставьте IP из письма):

```
cd C:\Users\Arman\OneDrive\Desktop\feramon
.venv\Scripts\python.exe deploy\make_archive.py
scp mona-site.zip root@IP:/root/
```

При первом подключении спросит `Are you sure you want to continue connecting?` — напишите `yes`. Потом введите пароль root из письма (буквы не видны — так и должно быть).

## 3. Запустить установку

```
ssh root@IP
```

(снова пароль root). Вы попали на сервер. Вставьте две строки:

```
python3 -c "import zipfile; zipfile.ZipFile('/root/mona-site.zip').extractall('/root/mona-setup')"
bash /root/mona-setup/deploy/setup_server.sh
```

Скрипт сам установит всё нужное (2–5 минут). В конце напишет:

```
ГОТОВО! Сайт работает: http://IP/
```

Откройте этот адрес в телефоне — сайт уже в интернете. Админка: `http://IP/admin/` (логин и пароль те же, что на компьютере).

## 4. Потом: домен и HTTPS

1. Купите домен `.kz` (на hoster.kz или ps.kz).
2. В настройках домена (DNS) добавьте две **A-записи**: `@` → IP сервера и `www` → IP сервера. Подождите 30–60 минут.
3. На сервере (`ssh root@IP`):

```
bash /srv/mona/deploy/add_domain.sh ваш-домен.kz
```

Сайт откроется по `https://ваш-домен.kz` с замочком.

## 5. Как обновлять сайт после изменений

После того как сайт заработал, **заказы, отзывы и фото живут на сервере**. Чтобы не затереть их, обновляйте только код:

```
cd C:\Users\Arman\OneDrive\Desktop\feramon
.venv\Scripts\python.exe deploy\make_archive.py --code-only
scp mona-site.zip root@IP:/root/
ssh root@IP "bash /srv/mona/deploy/update_site.sh"
```

Перед каждым обновлением скрипт сам делает копию базы в `/root/db-backup-…`.

## Если что-то пошло не так

Скопируйте последние строки из окна и пришлите — разберёмся.
Полезные команды на сервере: `systemctl status mona` (работает ли сайт), `systemctl restart mona` (перезапуск).
